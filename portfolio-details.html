Basesync - EV ECU Firmware Platform

Production-Grade EV ECU Firmware Platform

Basesync is a collaborative embedded systems project where I architected and developed a production-grade firmware platform for an Electric Vehicle Electronic Control Unit (ECU) from scratch. The platform targets STM32 ARM Cortex-M microcontrollers and is built to automotive reliability standards, with a full embedded DevOps pipeline that most embedded teams simply don't have.

The firmware uses a layered architecture (Application / Service / HAL) to ensure modularity, testability, and long-term maintainability. The EV state machine monitors battery and motor temperatures, current levels, and system health — automatically transitioning to a Safe State upon fault detection. CAN Bus messaging (0x100-0x1FF) handles real-time telemetry and sensor communication, while UART provides diagnostic logging.
